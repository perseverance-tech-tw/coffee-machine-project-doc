Module Design Specification (MDS)

Overview​

This section specifies the design of the software modules that make up the Smart Coffee Machine. It defines the responsibilities, interfaces, dependencies, and operational roles of each component identified in the Software Architecture Document.

The modules below are tailored for an embedded coffee-machine platform that integrates graphical user interaction, computer-vision cup detection, liquid-level monitoring, hardware control, and local data management. Particular emphasis is placed on:

  • Real-time responsiveness for user interaction and vision processing.
  • Accurate cup detection and position validation before dispensing.
  • Liquid-level monitoring to prevent overflow.
  • Operational safety during brewing and dispensing.
  • Robust handling of cameras, sensors, and hardware.
  • Maintainability and scalability for future enhancements.

These modules live under module/. For complete class- and function-level signatures, see the API Reference.

Module: aruco::aruco_detector​

Purpose — Define the interface and data structures for ArUco marker detection: detecting markers, annotating frames, estimating marker distance, loading camera calibration, converting rotation vectors, and evaluating reprojection accuracy.

Responsibilities

  • Define the ArucoDetector class interface.
  • Provide ArUco marker detection and frame annotation.
  • Support camera-calibration loading for accurate marker pose and distance estimation.
  • Convert rotation vectors into Euler angles.
  • Provide reprojection-error calculation for calibration and pose validation.
  • Expose detection results to other modules (camera processing, cup detection, calibration).

rvec_to_euler()Converts a rotation vector to Euler angles.Rotation vectorEuler angles
compute_reprojection_error()Computes reprojection error for calibration/pose accuracy.Object points, image points, calibration dataReprojection error

Module: camera::camera​

Purpose — Define the camera interface and supporting classes for frame capture, fisheye handling, focal-length access, and frame retrieval.

Responsibilities

  • Define the Camera class for managing camera operations.
  • Define the MoilUndistorter class for fisheye/lens-distortion correction.
  • Start and stop the camera.
  • Provide access to processed and raw frames.
  • Provide camera info such as fisheye status and focal length.
  • Support continuous capture via the camera loop.

Module: detections::cup::cup_detector_v2h​

Purpose — Define the cup-detection interface for the Renesas RZ/V2H platform: detect cup presence, validate position, process AI inference output, and retrieve results.

Responsibilities

  • Define the CupDetectorV2H class interface.
  • Cup detection via AI inference.
  • Validate whether the cup is at the required center point.
  • Process raw AI model outputs into usable detection results.
  • Retrieve inference result status.
  • Convert float16 output to float32 for post-processing.

Module: detections::cup::cup_measurement​

Purpose — Define the CupMeasurement data structure representing the estimated cup volume and size category, converting the volume-estimation result (fusion::VolumeResult) into a simplified form for the UI, brewing control, and dispensing logic.

Responsibilities

  • Define the CupSize enum for size classification.
  • Store estimated cup volume (mL) and the classified size category.
  • Provide a display label for the UI.
  • Convert fusion::VolumeResult into a CupMeasurement.
  • Provide a default "unknown" state for reset/invalid detections.
  • Avoid circular dependencies via forward declaration of fusion::VolumeResult.

unknown()Returns a default CupMeasurement (UNKNOWN, 0 mL).NoneDefault CupMeasurement

Module: detections::ai​

Purpose — Define the central AI-manager interface: a shared access point for initializing and managing AI components used by the detection pipeline.

Responsibilities

  • Define the AI class as the central AI manager.
  • Initialize AI resources required by detection modules.
  • Manage shared access to AI components for cup detection and computer vision.
  • Coordinate detection modules that require AI inference resources.
  • Ensure AI resources are prepared before detection runs.
FunctionDescriptionInputsOutputs
AI()Initializes the AI manager and prepares AI resources.NoneInitialized AI object

Module: detections::box​

Purpose — Define bounding-box and detection data structures with geometric operations: area, intersection, overlap, IoU, union, and non-maximum suppression (NMS).

Responsibilities

  • Define the Box class for bounding-box coordinates/dimensions.
  • Define the Detection class for detection results.
  • Provide geometric calculations (area, intersection, containment).
  • Calculate overlap and IoU between boxes.
  • Support box union and intersection.
  • Filter overlapping detections via NMS.

Module: detections::drp_queue​

Purpose — Define the DRP-AI job-queue interface that manages AI inference execution on the Renesas RZ/V2H, organizing tasks into a queue so hardware-accelerator resources are used safely and sequentially.

Responsibilities

  • Define the DRPJob class representing an AI inference job.
  • Define the DRPQueue class for managing queued tasks.
  • Enqueue DRP-AI jobs for scheduled execution.
  • Prevent simultaneous access conflicts to DRP-AI resources.
  • Support orderly AI processing for detection modules.
FunctionDescriptionInputsOutputs

enqueue()Adds a new DRP-AI inference job to the queue.DRPJob / inference taskQueued job status

Module: volume::cup_volume_estimator​

Purpose — Define the cup-volume-estimation interface to calculate the estimated liquid volume inside a cup, converting visual measurements (height, diameter) into a volume value.

Responsibilities

  • Define VolumeInput for input parameters.
  • Define VolumeResult for the estimated result.
  • Define the CupVolumeEstimator class interface.
  • Estimate volume from visual measurement data.
  • Calculate volume from cup height and diameter.
  • Apply exposure correction when required.
  • Provide results for cup measurement, UI display, and dispensing control.
