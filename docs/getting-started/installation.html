Installation & Setup

This guide describes how to set up the development environment, compile the source code, and prepare the Smart Coffee Machine application on a Linux (Ubuntu-based) host. For deployment on the Renesas RZ/V2H board, see Running the App.

1. System preparation​

The application supports the following environments:

  • Ubuntu Linux — recommended for direct hardware access.
  • Windows Subsystem for Linux (WSL) — supported for development on Windows (requires an Ubuntu distribution).

If you are using WSL, update your package lists first:

sudo apt update && sudo apt upgrade -y

2. Clone the repository​

git clone https://github.com/perseverance-tech-tw/coffee-machine-project-for-UCHI.git
cd coffee-machine-project-for-UCHI

3. Download the models​

The AI models for face and cup detection are not included in the repository and must be downloaded separately.

  1. Download models.zip from the latest release.
  2. Extract its contents.
  3. Create a models folder at the project root and copy the cup and face folders into it:
coffee-machine-project-for-UCHI/
├── models/
│   ├── cup/
│   └── face/

4. Install system libraries​

Install the required GTK and build tooling:

sudo apt install libgtk-3-dev pkg-config cmake build-essential git

Verify that GTK+ 3 is properly configured:

pkg-config --cflags gtk+-3.0
pkg-config --libs gtk+-3.0

The project also depends on OpenCV (computer vision) and GStreamer (camera/media handling):

sudo apt install -y libopencv-dev libgstreamer1.0-dev gstreamer1.0-plugins-base

:::note Windows (WSL) users You must also install GStreamer for Windows (MSVC 64-bit) on the host system to enable video streaming over the network. :::

Install FlatBuffers​

sudo apt install cmake git build-essential
git clone https://github.com/google/flatbuffers.git
cd flatbuffers
cmake -G "Unix Makefiles"
make
sudo make install
cd ..

5. Configure the camera​

Camera configuration is essential for face and cup detection. The application uses a CameraMultiplexer to manage multiple camera streams. In src/core/root_window.cpp, cameras are initialized in the on_activate method:

auto& multiplexer = CameraMultiplexer::get_instance();

multiplexer.create_camera("cup_cam", 2);
multiplexer.create_camera("face_cam", 0);
// multiplexer.create_camera("face_cam", "rtsp://172.18.16.1:554/live");

create_camera() takes two parameters:

  1. Camera name (string) — a unique identifier for the camera.
  2. Camera source (int or string) — a camera index (local camera) or an RTSP URL (network camera).
SetupExample
Single camera for both face & cupcreate_camera("cup_cam", 0); create_camera("face_cam", 0);
Separate camerascreate_camera("cup_cam", 1); create_camera("face_cam", 0);
RTSP / network streamcreate_camera("face_cam", "rtsp://172.18.16.1:554/live");

Tips

  • On Linux, camera indices usually start at 0. If a camera is not detected, try indices in the 0–10 range.
  • On WSL, if you cannot access the camera directly, use OBS to stream the camera feed over RTSP.
  • Check the terminal output for camera-initialization logs to confirm the cameras are connected.

6. Build the project​

Build manually with CMake:

rm -rf build
mkdir build && cd build
cmake ..
make
./smart-coffee-machine-fisheye-cpp

Or use the provided scripts from the project root:

./build.sh   # build
./run.sh     # build and run

Once the build succeeds, continue to Running the App.
