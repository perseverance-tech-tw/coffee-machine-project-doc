Detailed Description

PageRegistry provides a static central registry for PageStack subclasses, allowing pages to be registered by name and instantiated dynamically.

This works in tandem with the REGISTER_PAGE macro, which automatically registers PageStack subclasses at program startup. Manual calls to register_page() are optional if you use the macro.

Example usage:

// In MyPage.cpp
REGISTER_PAGE(MyPage);
// Later, create all registered pages and assign parent:
auto pages = PageRegistry::create_all_pages(root_window);

Notes:

  • Returned PageStack pointers are raw pointers. The caller is responsible for their lifetime (e.g., wrap in std::unique_ptr or manage via RootWindow).
  • The registry exists for the entire lifetime of the program (static storage).
  • Page names must be unique; registering a page with an existing name may overwrite the previous entry.
  • The factory functions are invoked in create_all_pages() to create new instances for each registered page.
