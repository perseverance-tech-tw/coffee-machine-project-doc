Ukur lebar rim gelas (piksel) via Otsu strip detection.

Mengambil strip 10% atas dari bbox, lakukan Otsu threshold, lalu cari kolom kiri-kanan yang ada piksel aktif. Lebih akurat dari bbox_w penuh karena tidak terpengaruh body yang lebih lebar.

Parameters
frameFrame BGR (sudah di-undistort)
bboxBounding box gelas dari YOLO
Returns
Lebar rim dalam piksel (selalu > 0, fallback 50% bbox width)
