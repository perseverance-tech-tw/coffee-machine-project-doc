Instantiate all registered pages and assign their parent.

Iterates over all registered page factories, creates instances, and sets the provided RootWindow as the parent of each page.

Parameters
parentPointer to the RootWindow to assign as parent.
Returns
Map of page name to PageStack* instance.
Note
Ownership:
  • The caller is responsible for deleting or managing the PageStack pointers returned by this function.
