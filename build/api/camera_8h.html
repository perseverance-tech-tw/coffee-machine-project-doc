Detailed Description

Declaration of the Camera class.

Camera provides continuous frame capture from a camera source and exposes the latest frame through a thread-safe API. Capture is performed on a dedicated background thread and stored in an internal buffer.

Fisheye mode (enabled via constructor): When fisheye=true, the Camera also maintains a Moil-undistorted copy of every raw frame. Both frames are accessible via get_frame() and get_raw_frame(). Moil parameters are passed at construction time (read from camera.json).

The camera source is represented as an integer:

  • int: V4L2 device index (e.g., 0 for /dev/video0)
