Detailed Description

A singleton class that manages named std::thread objects.

This class allows storing, retrieving, joining, and removing threads using human-readable string keys, such as:

  • "t_face_detection"
  • "t_audio_stream"
  • "t_logger"

Example:

ThreadController& tc = ThreadController::get_instance();
tc.add_thread("t_face_detection", std::thread([](){
// detection loop
}));
tc.close_thread("t_face_detection");
