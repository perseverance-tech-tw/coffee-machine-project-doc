Detailed Description

A singleton class that initializes and manages all AI-related modules such as face detection, alignment, and recognition.

This class ensures a single global instance for all AI subsystems, preventing redundant model loading and ensuring consistent use across the application.

Example:

AI* ai = AI::get_instance();
ai->face_detector->detect(img);
