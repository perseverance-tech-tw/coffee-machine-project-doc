Detailed Description

UI page responsible for cup placement detection and live camera preview.

This page manages:

  • Live camera rendering using a worker thread
  • Cup detection visualization
  • Auto navigation when cup is correctly placed
  • Auto timeout to return to main menu

Rendering pipeline:

  1. render_frame_thread continuously processes camera frames
  2. Processed frames are sent to GTK main loop via on_update_image_gui()
  3. Resulting image is displayed on image_canvas
