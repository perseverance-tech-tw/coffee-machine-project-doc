Screens

A walkthrough of the application's main screens. For the color palette and typography, see the Design System (Figure 1).

Standby​

Displayed after the machine is powered on and initial heating completes. It functions as an idle screen indicating the machine is ready for use. From here, users can access features such as system settings or face recognition for more personalized, automated service.

Cockpit Setting​

A system-configuration page accessible only from the Standby page. It provides administrative and technical functions not available to general users, intended for technicians or operators to perform maintenance, configure system settings, or shut down the machine.

Settings​

Used to adjust the preferences and configuration of the coffee machine. A Back button (top-left) returns to the previous page. The main area lists setting options with clear icons and labels for easy navigation and customization.

Main Menu​

The screen where users browse and select from available beverages. Drinks are shown in an organized layout for quick selection. A Settings button (bottom-left) opens the configuration menu.

Coffee Strength​

Used to adjust coffee strength. A Back button (top-left) returns without selecting. The main area shows options from 1 (weakest) to 10 (strongest). A Brew button (top-right) starts the process based on the selected strength.

Volume​

Where users select the amount of coffee to brew. A Back button (top-left) returns without changes. The main area presents volume options from 0.6 oz up to 12.0 oz for precise customization. A Brew button (top-right) initiates brewing using the selected volume.

Heating​

Displayed when the machine is first turned on or after a restart, informing the user that the system is warming up before it is ready to brew.

Cup Detection​

Monitors cup position and liquid level in real time before and during dispensing. It shows a live camera preview with detection results — the cup position, cup rim area, and liquid status — with the detected cup marked by a bounding box.

The system verifies that the cup is present and correctly aligned with the dispensing area before brewing continues, and monitors the liquid level to determine whether the cup is full. As shown in Figure 9, when the liquid reaches the predefined maximum level a warning such as "COFFEE IS FULL" is shown. This prevents overflow, reduces spills, maintains cleanliness, and ensures a safer dispensing process.

Brewing​

Displays the brewing process once preparation is complete. The machine extracts coffee according to the selected parameters while an animation/progress indicator shows the real-time status. It signals that no further interaction is needed until brewing finishes.

Finish Brew​

Displayed after brewing completes. It shows an animation of a full cup with a "Thank You" message, confirming the coffee is ready and the process is complete, before the machine returns to the main menu.
