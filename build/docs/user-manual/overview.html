User Manual — Overview

This user manual provides guidance for operating the Smart Coffee Machine, which integrates artificial intelligence, computer vision, embedded control, and a touchscreen interface to support a personalized and safe beverage-preparation process.

It is intended for end users, operators, and authorized personnel, and describes the main system workflow — startup, user recognition, beverage selection, cup-placement validation, brewing, settings access, and basic troubleshooting. The goal is to help users operate the machine correctly, efficiently, and in accordance with its intended design.

In this manual​

  • Features — the main features, including camera calibration, cup detection, settings mode, and face detection.
  • Using the Machine — step-by-step operation.
  • Troubleshooting — common issues and support contact.

:::tip Installing the software? This manual covers operation. For environment setup, building, and deployment, see Getting Started → Installation. :::
