Project Scope Document (PSD)

Introduction​

This project develops an advanced, AI-powered smart coffee machine based on the Jura X10 platform, designed to improve efficiency, cleanliness, and user convenience in automated beverage dispensing. The system addresses common operational issues — accidental spills, incorrect cup placement, and overfilling — by integrating precision cup detection and liquid-level monitoring through a high-resolution camera sensor system.

Using vision-based detection, the machine verifies whether a cup is present and correctly positioned before starting the dispensing process. During operation, it continuously monitors the liquid level inside the cup and automatically stops dispensing once the cup reaches the defined fill threshold. This prevents overflow, maintains hygiene, and ensures a consistent serving experience suitable for offices, hotels, cafés, restaurants, and self-service areas.

The system is built on the Renesas RZ/V2H platform for its strong AI-acceleration capabilities in real-time computer-vision tasks (object detection, liquid-level analysis, and fisheye lens-distortion correction). The operating environment is Yocto OS, a customizable embedded Linux platform. C++ is the core language, delivering the high performance, low latency, and precise hardware control required for reliable real-time automation.

Objectives​

Provide fast and accurate image-processing tools​

The system delivers high-performance visual analysis by leveraging the Renesas RZ/V2H processor and its dedicated Neural Processing Units (NPUs) for efficient AI acceleration. It employs YOLOv8s for real-time cup detection with high precision across varying lighting conditions, targeting a cup-detection accuracy above 95% to minimize operational errors.

Create an intuitive desktop UI for users​

The user interface is built with the GTK framework to provide a dynamic visual experience on touchscreens. It gives immediate feedback on cup placement; if the cup is outside the tolerance area or at risk of spilling, a clear warning is shown. This ensures safe, easy interaction with minimal user error and no technical expertise required.

Support an extensible architecture and multi-sensor integration​

Built on a customized Yocto OS environment, the system provides a scalable, modular embedded Linux architecture for integrating hardware drivers and AI frameworks. Using C++ for precise, stable hardware-resource management, functional modules (such as dual-camera systems and sensors) can be added flexibly without compromising performance, supporting long-term maintainability and future feature development.

Technology stack​

  • Software development: C++, Yocto OS, Linux
  • Computer vision & machine learning: YOLOv8s, Renesas NPU / AI inference engine
  • UI/UX: GTK, touchscreen interface

Constraints​

  • The system must operate strictly within the computational resources of the Renesas RZ/V2H SoC.
  • All user data is processed and stored locally in an encrypted database.
  • The computer-vision system must enforce a strict positioning tolerance of 1 cm for cup placement.
  • Detection accuracy for water levels and cup positioning must remain robust under varied lighting conditions and with different container materials.
  • The software architecture is constrained to the Yocto-based embedded Linux environment.

Development phases​

The project is delivered in distinct phases to ensure manageable progress and clear milestones.

Phase 1 — Foundation & Core Recognition​

  • Objective: Develop the core smart coffee machine on the Jura X10 platform, integrating the Renesas RZ/V2H processor to enable basic AI-driven personalization and safety features.
  • Key features: Cup-positioning detection (YOLOv8 verifies presence and alignment to prevent spills); responsive C++/GTK touchscreen interface; hardware integration (RZ/V2H board, dual-camera system, Yocto OS environment).
  • In scope: Cup detection, Yocto OS customization.
  • Out of scope: Cloud connectivity, cup recognition.

Phase 2 — Cup Recognition & Power Saving​

  • Objective: Extend the system with cup-size recognition and energy efficiency.
  • Key features: Cup-size recognition (YOLOv8s classifies cups into small/medium/large); auto-adjustment of brewing (water volume, extraction time, dosage based on detected size); energy-saving trigger (LDR sensors power cameras only when needed); optimization via the DRP-AI accelerator for low-latency edge inference.
  • In scope: Object recognition for size classification (S/M/L), automatic parameter adjustment, power-management system, 3D-printed model machine.
  • Out of scope: IoT/cloud integration, mobile-application control.

Phase 3 — Water-Level Measurement​

  • Objective: Implement a robust, camera-based water-level monitoring system for continuous operation and proactive maintenance alerts.
  • Key features: Visual water-level monitoring (no float sensors); proactive low-water alerts before brewing; adaptive brewing logic when the level is marginal; environment adaptation for lighting, reflections, and container transparency.
  • In scope: Water-level detection algorithm, refill notification, handling transparency and lighting variation in the water tank.
  • Out of scope: IoT/cloud integration.

Stakeholders​

The success of the Coffee Machine project depends on collaboration among the following stakeholders:

  • Product Owner — defines product vision, prioritizes features, ensures alignment with business goals.
  • Project Manager — oversees timeline, resources, and overall execution.
  • Software Developers — develop core image processing, AI features, and application logic.
  • Embedded Engineer — manages hardware setup (Kakip RZ/V2H board, camera-sensor integration, LDR sensor wiring, firmware configuration).
  • Mechanical Designer — designs the physical structure, CAD models for camera mounts and enclosure, and manages 3D printing and assembly.
  • QA Team — ensures product quality through rigorous testing and validation.
  • End Users — home and office users who interact with the machine for a personalized, automated coffee experience.
