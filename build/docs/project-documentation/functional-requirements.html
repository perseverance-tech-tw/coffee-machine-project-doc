Functional Requirements Specification (FRS)

Overview​

The Smart Coffee Machine is an intelligent brewing solution that integrates artificial intelligence and computer vision into a high-performance embedded system. Built on the Jura X10 machine platform and powered by the Renesas RZ/V2H processor, it delivers a fully automated, personalized, and hygienic user experience.

Functional requirements​

AI & computer-vision processing​

FR-1.1 — Cup detection & size classification​

The system shall use the YOLOv8s model to detect the presence and position of a cup within the dispensing area, and verify that the cup is properly aligned under the coffee outlet before dispensing begins (see Figure 9). If the cup is missing or misaligned beyond the defined tolerance, the system shall prevent dispensing.

In addition, the system shall monitor the liquid level inside the cup in real time to determine whether it is empty, partially filled, or full. When the liquid reaches the predefined maximum threshold, the system shall automatically stop dispensing and display a warning to prevent overflow, reduce spills, and maintain cleanliness.

FR-1.2 — Visual water-level monitoring​

The system shall continuously monitor the water-reservoir level using computer-vision analysis, eliminating the need for physical float sensors. It shall trigger a user-facing alert on the UI if the water level is insufficient to complete the selected brew cycle.

Brewing control system​

FR-2.1 — Adaptive parameter adjustment​

The control logic shall automatically adjust brewing parameters — water volume, extraction duration, and coffee dosage — based on the detected cup-size classification, maintaining the optimal coffee-to-water ratio regardless of the container used.

FR-2.2 — Safety interlocks​

The system shall inhibit the dispensing of hot liquid if no cup is detected or if the cup is improperly positioned.

UI requirements​

FR-3.1 — Main interaction layout​

The interface, built with GTK/C++, shall provide a responsive touch experience on a 10-inch display, with real-time visual feedback including bounding boxes for cup detection and progress bars for brewing status.

FR-3.2 — Operational screens​

  • Standby page (Figure 2) — displays time/date and allows access to settings or login.
  • Main menu (Figure 5) — displays available coffee types (e.g., Latte, Cappuccino) with clear iconography.
  • Customization pages (Figure 6, Figure 7) — allow users to adjust coffee strength (scale 1–10) and volume (0.6 oz – 12 oz).
  • Brewing page (Figure 10) — visualizes the current stage (heating, extracting, pouring) and notifies completion.

FR-3.3 — Admin & maintenance cockpit​

The system shall provide a restricted Cockpit/Settings menu for technicians to configure hardware parameters (e.g., water hardness) and perform maintenance tasks.

User interaction flow​

The interaction begins when the machine is powered on and enters the standby state. The flow guides the user from beverage selection to dispensing, while ensuring correct cup placement and preventing overflow through real-time cup and liquid-level monitoring.

Logical steps

  1. Initialization & standby — the machine is powered on and waits for user interaction.
  2. Beverage selection — from the standby page, the user selects a beverage. The system checks whether the item is a coffee beverage or a non-coffee ingredient. A coffee beverage continues to customization; a non-coffee item follows its corresponding flow without coffee-strength adjustment.
  3. Coffee customization — the user sets coffee strength, then volume.
  4. Cup detection & brewing validation — before brewing, the system verifies that a cup is present and located at the required center point. If not correctly positioned, the machine does not dispense; dispensing proceeds only once the position is validated.
  5. Brewing process — the machine dispenses the beverage according to the selected settings and monitors the process in real time.
  6. Liquid-level monitoring & completion — while brewing, the system monitors the liquid level and automatically stops if it reaches the maximum threshold. On completion, the Finish Brew page is shown and the flow ends.
