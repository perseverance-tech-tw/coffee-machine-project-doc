Detailed Description

UI page responsible for live face detection and camera preview.

This class manages:

  • Live rendering of camera frames (worker thread)
  • Updating GTK image widgets from background threads
  • Auto-idle detection (returns user to standby when inactive)
  • Navigation to other UI pages

The rendering pipeline:

  1. render_frame_thread continuously processes camera frames.
  2. Processed frames are passed to GTK main loop via on_update_image_gui().
  3. The image is displayed on image_canvas.
