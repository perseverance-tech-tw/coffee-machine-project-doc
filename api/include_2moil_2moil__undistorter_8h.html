Include HANYA file ini dari proyek yang menggunakan mod_moil: #include <moil/moil_undistorter.h>

Port dari: 07_midas_aruco_fusion/core/moil_undistorter.h Dipaketkan sebagai shared library (mod_moil) dengan pola backup_module.
