Detailed Description

Singleton that multiplexes multiple logical camera names over shared sources.

One-camera-per-source policy:

  • Same source → shared Camera instance.
  • Re-creation on same source → refreshes the Camera for all users.
  • Source with no remaining users → released automatically.

All public operations are guarded by an internal mutex.

cv::Mat CameraMultiplexer::get_nv12_frame ( const std::string & name)

Get the latest processed frame as NV12 (CV_8UC1, rows=H*3/2).

Use this for DRP-AI consumers (CupDetectorV2H, MidasEstimatorV2H, FaceDetectorV2H) that feed frames into FORMAT_NV12_420 DMA buffers. Avoids BGR conversion overhead compared to get_frame().

◆ get_pipeline_gen()

uint32_t CameraMultiplexer::get_pipeline_gen ( const std::string & name)

Get the pipeline generation counter for the specified camera.

Incremented every time the GStreamer pipeline is (re)opened, including automatic restarts after consecutive frame failures. Consumers such as the cup detection thread can watch for changes and reset their warmup counters to avoid running inference on garbage frames after a restart.

Parameters
nameLogical camera identifier.
Returns
Generation counter (starts at 0 before first open), or 0 if not found.
