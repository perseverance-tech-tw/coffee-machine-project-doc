Detailed Description

GTK navigation bar with left, center, and right controls.

This widget manages:

  • Left button (default Back behavior)
  • Center label (current page/home title)
  • Right button (Next/forward action)

Signals for left/right buttons can be dynamically reconnected using reconnect_signal() or reconnect_signal_after().

Integration with RootWindow:

  • Uses RootWindow to navigate page stack history.
  • Default behavior for the left button is to switch to the previous page.

Ownership:

  • The Navigation object owns the root GTK widget (widget).
  • GTK manages the child widgets (left_side, center_side, right_side).
  • Signal connections are automatically disconnected in the destructor.
