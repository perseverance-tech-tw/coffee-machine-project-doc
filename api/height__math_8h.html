Detailed Description

Struct BBox dan fungsi math untuk estimasi tinggi gelas (7 mode kalibrasi).

Include file ini di proyek yang membutuhkan kalkulasi tinggi gelas: #include <volume/height_math.h>

Port dari: 07_midas_aruco_fusion/core/height_math.py Dipaketkan sebagai bagian dari mod_volume dengan pola backup_module.
