Detailed Description

Contains shared data used by face detection and recognition threads.

This struct holds:

  • The latest camera frames
  • Detected faces and ROIs
  • Recognition results
  • Embedding vectors
  • Recognition state and metadata

All fields in this struct are meant to be accessed only when protected via ThreadFaceLockData::face_data_mutex to ensure thread safety.
