Detailed Description

Public API untuk mod_moil — Fisheye undistortion via shader math (CPU C++).

Drop-in replacement untuk module/moil versi lama (libmoildevren.a). API identik — tidak ada perubahan di sisi pemanggil (camera.cpp, dll).

Include path sama persis: #include <moil/moil_undistorter.h>

Implementasi menggunakan rumus matematika yang diport dari shader GLSL (anypoint_mode1.frag, anypoint_mode2.frag, panorama_car.frag, panorama_tube.frag) — tanpa dependensi library biner apa pun.

Formula inti (sama di semua shader): rho = (p0*α⁶ + p1*α⁵ + p2*α⁴ + p3*α³ + p4*α² + p5*α) * cpRatio sourceX = iCx - rho * cos(β) sourceY = iCy - rho * sin(β)

Mode yang didukung: 1 = Anypoint Mode 1 (alpha/beta 3D projection, shader: anypoint_mode1.frag) 2 = Anypoint Mode 2 (pitch/yaw 3D projection, shader: anypoint_mode2.frag) 3 = Panorama Car (Rodrigues rotation, shader: panorama_car.frag) 4 = Panorama Tube (cylindrical equirectangular, shader: panorama_tube.frag)
