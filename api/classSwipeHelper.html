Detailed Description

Helper class untuk menangani swipe gesture pada GTK widget.

Fitur:

  • Support swipe horizontal (left/right)
  • Configurable velocity threshold
  • Callback-based untuk handling swipe events
  • RAII pattern untuk automatic cleanup
  • Thread-safe
