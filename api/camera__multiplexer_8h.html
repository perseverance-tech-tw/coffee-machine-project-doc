Detailed Description

Declaration of the CameraMultiplexer class.

CameraMultiplexer is a thread-safe singleton responsible for managing Camera instances. Each unique source (device index or stream URL) maps to a single canonical Camera object that may be shared by multiple logical camera names.

Fisheye support: create_camera() and create_fisheye_camera() allow registering a logical name with or without Moil undistortion. When fisheye is enabled, the underlying Camera maintains both a raw frame and a Moil-processed frame.

  • get_frame() → returns processed (undistorted) frame
  • get_raw_frame() → returns original fisheye frame (for mod_volume)
