Detailed Description

Threaded camera capture wrapper with optional Moil fisheye undistortion.

A Camera instance owns a capture thread that repeatedly opens the configured source, reads frames, and stores the newest frame in memory.

When fisheye mode is enabled:

  • get_frame() → returns the Moil-undistorted frame
  • get_raw_frame() → returns the original fisheye frame (needed by mod_volume)

When fisheye mode is disabled:

  • get_frame() → returns the frame as-is
  • get_raw_frame() → returns the same frame as get_frame()
Note
This class is designed to be used by CameraMultiplexer.

◆ get_frame()

cv::Mat Camera::get_frame ( )

Get the latest processed frame as BGR (CV_8UC3).

If fisheye mode is enabled, returns the Moil-undistorted frame converted from NV12 → BGR. Otherwise returns the raw frame as BGR. This is the primary accessor for display and detection consumers (YOLO, ArUco, Face).

Returns
Latest BGR frame or empty cv::Mat.

◆ get_nv12_frame()

cv::Mat Camera::get_nv12_frame ( )

Get the latest processed frame as NV12 (CV_8UC1, rows=H*3/2).

Returns the undistorted frame in raw NV12 format without color conversion. Use this for DRP-AI consumers (cup detector, MiDaS, face detector) that feed directly into FORMAT_NV12_420 DMA buffers, avoiding BGR overhead.

Returns
Latest NV12 frame or empty cv::Mat.

◆ get_raw_frame()

cv::Mat Camera::get_raw_frame ( )

Get the latest raw (non-undistorted) fisheye frame as BGR (CV_8UC3).

Always returns the original frame from the sensor as BGR. This is what mod_volume (CupVolumeEstimator) needs as input.

Returns
Latest raw BGR frame or empty cv::Mat.
