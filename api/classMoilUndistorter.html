Detailed Description

Fisheye undistortion wrapper menggunakan Moildev (via libmoildevren.a).

Fisheye undistortion menggunakan pure C++ math dari shader GLSL.

C++ port dari core/moil_undistorter.py.

Contoh penggunaan:

MoilUndistorter moil("camera_parameters.json", "syue_7730v1_6",
pitch, yaw, roll, zoom, mode);
cv::Mat corrected = moil.undistort(raw_frame);
cv::Mat K = moil.build_aruco_camera_matrix(width, height);

Definition moil_undistorter.cpp:113

Workflow:

  1. Baca parameter kamera dari JSON (sama seperti sebelumnya)
  2. Pre-compute remap maps (map_x, map_y) menggunakan rumus shader
  3. Setiap frame: cv::remap() saja — minimal processing, hasil serahkan ke shader/moil math

Contoh penggunaan (identik dengan versi lama):

MoilUndistorter moil("camera_parameters.json", "syue_7730v1_6",
pitch, yaw, roll, zoom, mode,
cap_width, cap_height);
cv::Mat corrected = moil.undistort(raw_frame);
cv::Mat K = moil.build_aruco_camera_matrix(width, height);

◆ undistort() [2/2]

cv::Mat MoilUndistorter::undistort ( const cv::Mat & frame)

Terapkan fisheye undistortion ke satu frame NV12.

Input diterima dalam format NV12 (YUV 4:2:0 semi-planar) — format native dari GStreamer pipeline (format=NV12).

Layout NV12 dalam OpenCV (CV_8UC1, rows = H*3/2): Row 0..H-1 : Y plane (luma, full resolution) Row H..H*3/2-1 : UV plane (chroma, interleaved U,V, half resolution)

Pipeline:

  1. Split Y plane (H×W) dan UV plane (H/2 × W/2)
  2. Remap Y dengan full-res map (map_x_, map_y_)
  3. Remap UV dengan half-res map (map_x_uv_, map_y_uv_)
  4. Stack kembali ke NV12 output
Parameters
frameFrame NV12 input (CV_8UC1, rows = H*3/2)
Returns
Frame NV12 setelah undistortion (CV_8UC1, rows = H*3/2)
