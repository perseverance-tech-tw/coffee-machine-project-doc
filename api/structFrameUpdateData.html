Detailed Description

Helper struct used to safely pass image data to GTK main thread.

Helper struct for passing image data safely to GTK main thread.

GTK requires that UI updates occur on the main loop, so worker threads pass their new frame using this structure.

GTK UI updates must occur on the main loop. Worker threads use this struct to transfer rendered frames.
