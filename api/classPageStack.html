Detailed Description

Base class for all UI pages inside the application's view stack.

Each PageStack corresponds to one screen or UI page in the application. The class provides:

  • Automatic loading of .glade UI files
  • Standardized lifecycle hooks:
    • init()
    • connect_signals()
    • on_page_changed()
    • on_page_hidden()
  • Metadata such as page index and name

Subclasses must implement:

  • get_page_name()
  • (optionally override init() and connect_signals())

Example:

PageStack* p = PageStack::create<MyPage>();
root_window->push_page(p);
