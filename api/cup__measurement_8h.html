Detailed Description

Struct CupMeasurement — hasil estimasi volume & ukuran gelas.

Dihasilkan dari fusion::VolumeResult (mod_volume) via factory function CupMeasurement::from_volume_result().

Include header ini di seluruh UI layer. Jangan include cup_size_estimator.h yang sudah tidak ada.
