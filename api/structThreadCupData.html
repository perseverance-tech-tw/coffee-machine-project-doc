Detailed Description

Contains shared data used by the cup detection pipeline.

This struct holds:

  • Latest camera frame
  • Detection and estimation results
  • Cup position metadata
  • Current pipeline state

All members must be accessed only while holding ThreadCupLockData::cup_data_mutex.
